# Gross Pay Calculator
A python program that calculates gross pay on given hours and rate (payment per hour).

## installation and setup
1. Open your terminal and navigate to your directory:
```bash
cd gross-pay
```
2. Run the program.
```bash
python pay.py
```
## Usage Example
Enter Hours: 35 <br>
Enter Rate: 2.75 <br>
Pay: 96.25
